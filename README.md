This portfolio showcases:

* My projects

* About me
* Contact information

* React
* Vite
* JavaScript
* CSS

## Features

* Responsive design
* Modern UI
* Fast performance
* Smooth navigation

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/portfolio.git
```

Go to the project folder:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
